# Lab 01 — Small Business Network

## Overview

This project demonstrates the design, configuration and troubleshooting
of a small business network using Cisco Packet Tracer.

## Objectives

- Configure VLANs
- Configure trunking
- Configure inter-VLAN routing
- Configure DHCP
- Configure NAT
- Configure SSH
- Implement a basic ACL
- Test end-to-end connectivity
- Document network configuration
- Perform structured troubleshooting

## Technologies

- Cisco IOS
- Cisco Packet Tracer
- IPv4
- VLAN
- 802.1Q trunking
- Inter-VLAN routing
- DHCP
- NAT
- ACL
- SSH

## Network Devices

- 1 Cisco Router
- 1 Cisco Switch
- 2 PCs
- 1 Server
